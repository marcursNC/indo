# Indonésie 2026 — Java & Bali

Carnet de voyage interactif pour un voyage en duo en Indonésie, du 8 au 29 décembre 2026.

## Contenu

- Itinéraire jour par jour
- Carte interactive Java → Bali
- Hébergements et étapes
- Transports entre les étapes
- Activités et expériences
- Budget de voyage
- Réservation Alasari Hidden Bamboo Retreat intégrée
- Mise en page responsive pour mobile et ordinateur

## Publication avec GitHub Pages

1. Créer un dépôt GitHub, par exemple `indonesie-2026`.
2. Importer tous les fichiers de ce dossier.
3. Dans **Settings → Pages**, choisir **GitHub Actions**.
4. Pousser la branche `main`.
5. GitHub publiera le site via le workflow fourni.

## Note

Le site utilise Leaflet, OpenStreetMap et certaines images distantes. Une connexion Internet est nécessaire pour profiter pleinement de la carte et des images externes.

Les informations de voyage, tarifs et horaires sont des données de planification et doivent être vérifiés avant réservation.
